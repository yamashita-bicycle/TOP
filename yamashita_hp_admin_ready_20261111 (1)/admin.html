① ファイルをダウンロードして更新

最初はこちらの方法が簡単。パスワードや特別な設定は不要です。

  1. 変更した方のJSONファイルをダウンロード
  2. GitHubのリポジトリを開く
  3. Add file → Upload files から同名ファイルを上書きアップロード
  4. Commit changes を押して更新完了

営業日だけ変更した場合は schedule.json、お知らせだけの場合は news.json の更新でOK。index.htmlの編集は不要です。

② バックアップから復元

以前ダウンロードしたJSONファイルを選択すると、この画面に読み込めます。

GitHubへ直接公開 （任意）

一度設定すると、JSONのダウンロードなしでGitHubに反映できます。

注意：この管理ページ自体にパスワード制限はありません。公開操作にはGitHubの書き込み権限が必要です。トークンはこの画面でのみ使用し、保存しません。
対象リポジトリの Contents: Read and write 権限のみ

対象：yamashita-cycle/yamashita-bicycle / ブランチ main。トークンを使う場合は有効期限を短めにし、他の人に見せないでください。

ファイルについて

お知らせと営業日は別々のデータファイルです。

schedule.json：各日付の昼間・夜間・休業を保存

news.json：お知らせの文章・公開／非公開・並び順を保存

GitHub Pagesへの反映には多少時間がかかる場合があります。
